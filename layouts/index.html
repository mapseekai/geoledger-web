01 / DATA MODEL

要素级粒度，项目级修订

通过稳定的字符串 ID 追踪每个空间要素的生命周期。支持在单个修订中原子提交跨多个图层（点、线、面）的协同更新。

 02 / POSTGIS

纳管既有 PostGIS 业务表

无需搬迁存量数据即可接入受约束的现有业务表，完整保留源表 SRID 与主键，发布时在同一事务内同步写回原表。

 03 / MERGE

属性级三方合并与几何冲突

基于共同基线（Base）对比最新共享状态（Current）与草稿（Draft），自动合并独立属性，将几何变更作为完整空间单元严谨比对。

 04 / SCHEMA

版本化字段定义（Schema）

在工作区中声明普通属性字段的新增与删除，随要素修改一同审阅和发布，支持按任意历史修订读取当时的表结构。

 05 / CORRECTNESS

事务原子性与幂等发布恢复

正式数据、历史记录、审计日志与发布回执同提交同回滚。遇到网络超时或断连时，可凭原请求 ID 安全重放并确认发布结果。

 06 / HISTORY

时间旅行查询与非破坏性撤销

随时固定修订号查询历史快照与空间范围。撤销历史提交时自动生成反向变更工作区，经审阅后发布为新修订，完整保留历史轨迹。

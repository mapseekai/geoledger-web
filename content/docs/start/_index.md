按以下顺序完成入门：

1. 阅读[认识 GeoLedger]({{< relref "/docs/start/introduction/" >}})，了解项目、数据集、工作区和修订。
2. 按[快速开始]({{< relref "/docs/start/quickstart/" >}})启动服务并完成首次登录。
3. 用[第一次发布]({{< relref "/docs/start/first-publication/" >}})观察草稿与共享数据的区别。
4. 需要程序接入时，继续 [Python SDK 教程]({{< relref "/docs/start/sdk/" >}})。

教程使用合成数据。它们以跑通一条学习路径为目标；真实环境的部署与恢复要求见[运维指南]({{< relref "/docs/operations/" >}})。
